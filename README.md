# 若水漫画

[English](README.en.md) · [下载 / Releases](https://github.com/Penumbrill/ruoshui-comic/releases)

面向初学者的 Windows 本地 AI 漫画创作软件，支持单图生成、局部重绘、分镜排版和提示词助手。

## 开始使用

推荐下载 Release 中的 **`若水漫画-安装版.exe`**。选择安装目录后，小安装器从本仓库 Release 下载程序和独立运行环境，通过 SHA-256 校验后解压。它自动尝试环境代理、Windows 系统网络与直连，在 GitHub 下载地址及备用接口之间切换，不修改系统网络设置。下载中断后重新运行安装器可继续下载。

安装位置可选择 D、E 等其他盘。安装完成后，软件目录自动加入当前用户 PATH，新打开的终端可直接运行 `若水漫画.exe`；卸载仅移除本软件添加的 PATH 项，已有环境变量保留。

软件每次启动也会自动检测并补齐 PATH，解压运行整合包同样生效；“设置 → 电脑环境与运行时”显示配置状态并提供“检测并修复 PATH”。内置运行工具在软件自己的进程环境中自动识别。

**离线整合包：**下载同一 Release 的 `ruoshui-comic-update-win-x64.zip` 和全部 `ruoshui-runtime-win-x64-*.zip`，全部解压到同一个空文件夹，保留相对路径。它们是可分别解压的普通 ZIP，不是分卷；不可只解压其中一个。`ruoshui-setup-guide.zip` 包含双语说明与 SHA-256 校验工具。将原始 ZIP 和说明包内容放在同一文件夹，运行 `校验整合包.cmd` 可校验包内容。

所有包均不含模型权重、私人设置和示例作品。完整程序与运行环境仍需下载约 3 GB，解压约 5 GB；安装时还需缓存空间，模型空间另计。请选择可写、空间充足的专用文件夹，不要安装进其他软件或源码目录。

1. 便携版解压后，双击 `若水漫画.exe`。安装版运行安装程序，选择安装位置。
2. 在“设置 → 电脑环境与运行时”检查电脑环境。缺少必要组件时，按提示下载安装。
3. 在“生图模型与下载”准备模型。整合包不含模型权重，可在软件内下载或导入。
4. 输入场景并生成图像。生成过程中可以切换工作区，队列进度会显示在底部。
5. 在漫画制作中选择分镜模板、放入图片，添加对白、文本及贴纸，导出 PNG 或可编辑项目。

便携版请保留整个文件夹，不能只复制 EXE。选择有写入权限、空间充足的目录；软件会根据当前位置识别自己的运行环境和数据。

## 提示词与标签

完整词库包含 11 个分类、133 个分组、3957 个初始标签。所有提示词入口共用词库，支持搜索、收藏、分类与分组管理、标签编辑、排序和批量操作。

可以导出完整 JSON 或 SQL 词库，也可以导入、合并或恢复修改前的备份。提示词标签支持鼠标拖动排序；移动鼠标到标签上会显示编辑工具。

提示词助手支持本地语言模型和可选线上接口。点击“下载模型”可下载默认语言模型，完成后选择并使用。参考图片需要配套视觉投影模型。默认质量词可以关闭，改用自己填写的质量词，也可以留空。

## 分镜与重绘

分镜支持 3–32 边轮廓、斜框、透明主体破框和抠图自动对齐原图。文本可选横排或竖排，支持粗体、斜体、下划线与对齐；自带 24 款中英文字体，也可选择系统字体或导入 TTF、OTF、WOFF、WOFF2。导入字体保存在 `works/fonts`。

各类图像预览使用滚轮缩放、双击适合窗口；漫画主画布使用 Ctrl + 滚轮。坐标、尺寸、字号和其他数值参数可滚轮调整，Shift 加快；各参数提供恢复按钮，设置内可恢复全部参数。分镜生成预览保留完整图像，可开关半透明参考框并调整透明度。

分镜标明准备放入的页码与格数。双击软件生成的分镜图片，会打开该图片独立的图像、提示词和参数窗口；重绘结果打开独立重绘窗口，外部导入图片不会自动打开生成窗口。

单次和连续生成的图片会保留在该分镜的候选列，点击候选即可填入。局部重绘先涂抹需要修改的区域，再描述修改内容；遮罩外保留原图。

预览区顶部有“上传图片”和“从画廊选择”；也可将 PNG、JPG、WebP 图片直接拖进预览区。切换新原图后清空旧遮罩。单图与分镜生成窗口共用这些入口。

文本、对白与贴纸分别管理。点击空白处或按 Esc 取消选择；右键可删除选中对象，多选文本框时还可粘连或取消粘连。左右功能区之间的分隔条可拖动调整宽度。

图层右键菜单支持组内上移/下移以及跨类型图层上移/下移。弹窗标题随内容滚动，仅关闭按钮固定。

除下载窗口外，点击弹窗外的空白处会保存有效修改并关闭。删除和卸载确认窗口点击空白处只取消操作。

## 图片与个人数据

作品、设置、自动保存、聊天、词库和日志均保存在软件目录的 `works` 文件夹。模型和运行环境保存在 `runtime`。请定期备份 `works`。

模型自动下载到当前软件目录 `runtime/ComfyUI/models` 的对应分类，提示词助手模型在其中的 `llm` 子目录。移动整合包后，后续下载跟随新位置。单图生成与局部重绘不会自动导入漫画；只有从具体分镜打开时才回填结果。

漫画 PNG 自动保存到 `works/exports/项目名称` 子文件夹，导出按钮旁提供“打开漫画文件夹”。程序更新保留运行环境；升级运行环境时请使用同一 Release 的运行环境 ZIP 或重新运行安装器。

画廊支持单张与多选删除。图片关联的生成参数、遮罩及专属草稿一起进入回收区，恢复时一起恢复；已经放进漫画的图片仍可显示。

设置中的缓存管理只清理可重新生成的临时文件，保留作品、模型、聊天、登录信息和未完成下载。

## 更新与卸载

“设置 → 更新与卸载”可以检查新版本、查看更新公告及下载进度，并暂停、继续或重试。更新保留模型和创作数据。

卸载时可以选择保留模型及个人创作。取消保留后，对应内容将永久删除，请先备份。

## 组件许可

随软件分发的第三方组件及模型遵循各自许可。必要的许可证、版权声明和来源信息保存在资源目录及各组件目录的许可文件中。

## 开发

使用 `npm run dev` 启动开发版，`npm test` 运行检查，`npm run build` 构建界面。发布脚本须在获得打包授权后运行，不会自动提交、上传或发布。

首次开发先运行 `npm ci`。源码不含运行环境，实际生成需要将 Release 的运行环境 ZIP 解压到项目根目录，或在设置中准备环境和模型。当前发布目标为 Windows x64。

经明确授权后，执行 `node scripts/online-release.mjs --approved` 构建安装器及整合包；脚本不会自动上传。本机 `runtime` 必须已准备好。发布输出位于同级 `manhua-发布/纯净整合包` 和 `manhua-发布/安装版`，临时构建和测试数据在 `works`。
