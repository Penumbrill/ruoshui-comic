# 若水漫画 · Ruoshui Comic

[English](README.en.md) · [下载安装](https://github.com/Penumbrill/ruoshui-comic/releases/latest) · [反馈问题](https://github.com/Penumbrill/ruoshui-comic/issues)

面向初学者的 Windows 本地 AI 漫画创作软件。从生成画面、局部修改，到分镜排版、添加对白和导出漫画，在同一个工作区完成。

自带独立运行环境，无需另外安装或配置其他绘图软件。模型按需下载，作品和项目保存在本机。

## 主要功能

- **图像生成与局部重绘**：根据提示词生成图片，涂抹指定区域修改细节；支持上传图片、拖放导入和画廊选图。
- **漫画分镜与排版**：管理多页项目，使用分镜模板，调整斜框和多边形轮廓，组合图片、对白、文字和贴纸。
- **抠图与破框效果**：自动识别主体，手动修边，让人物或物品延伸到分镜外，并可一键对齐原图。
- **文字与对白**：支持对白粘连、横竖排文字、字体选择和格式调整；自带中英文字体，也可使用系统字体或导入字体文件。
- **提示词与标签**：提供分类词库、模糊搜索、收藏与导入导出；提示词助手可使用本地模型或可选的在线服务。
- **保存与导出**：自动保存编辑内容，管理本地画廊，导出漫画 PNG 或完整项目 ZIP。项目压缩包包含图片、贴图、字体、工程文件和最后编辑状态，导入后自动恢复。

删除项目时可以选择保留图片，或将关联内容一起移入回收区；其他项目使用的图片会保留，误删的项目可在本地回收区恢复。

在“设置 → 缓存与存储”可以查看回收区、恢复项目和图片，或确认后一键清空。回收区不会自动清理；永久删除后无法恢复。

## 系统与空间要求

| 项目 | 说明 |
| --- | --- |
| 系统 | Windows 64 位；当前发布包为 x64 版本 |
| 显卡 | 建议使用支持 CUDA 的 NVIDIA 显卡；生成速度与显存需求取决于模型、分辨率和功能 |
| 内存 | 建议 16 GB 或更多 |
| 磁盘 | 程序与运行环境下载约 3 GB，解压约 5 GB；安装缓存和模型需要额外空间 |
| 网络 | 首次下载程序、运行环境和模型时需要联网；在线标签检索及可选在线助手也需要联网 |

本地生图使用软件自己的 Python、推理依赖和引擎目录。显卡驱动使用系统已安装的驱动。

## 下载与安装

从 [GitHub Releases](https://github.com/Penumbrill/ruoshui-comic/releases/latest) 下载安装文件。安装器与手动解压两种方式，任选一种即可。首次启动会自动下载中译英、英译中两套翻译模型，下载进度可在软件中查看。图像生成模型可在软件内下载。本地助手模型若有匹配的 mmproj 视觉组件，会一并下载并自动关联；已有且通过校验的文件会跳过。

提示词助手的搜索、文件查询和下载共用“设置 → 提示词助手 / AI 接口”中的下载源设置。镜像可访问时无需网络加速器；若官网与镜像均连接失败，请连接网络加速器后重试。模型下载完成后可离线使用。

大文件支持最多 4 路分段下载；线路异常时降低并发、切换来源并保留已完成分段。下载面板显示实际来源、连接方式与下载节点。镜像可能重定向到原站的文件节点，实际速度取决于当前网络线路。

### 方式一：使用安装器

1. 下载并运行 **`ruoshui-comic.exe`**。
2. 选择安装文件夹，可选择 D、E 等其他盘。
3. 等待安装器下载程序和运行环境，完成校验与解压后启动软件。

安装器支持下载续传，并自动尝试可用的网络连接方式。中断后重新运行安装器即可继续安装。安装完成后通过桌面快捷方式或安装目录里的 **`ruoshui-comic.exe`** 打开软件。

### 方式二：手动解压整合包

下载同一 Release 中的以下 **5 个 ZIP**：

| 文件 | 内容 |
| --- | --- |
| `ruoshui-comic.update-win-x64.zip` | 主程序，首次安装也需要 |
| `ruoshui-runtime-win-x64-01.zip` | 运行环境第 1 包 |
| `ruoshui-runtime-win-x64-02.zip` | 运行环境第 2 包 |
| `ruoshui-runtime-win-x64-03.zip` | 运行环境第 3 包 |
| `ruoshui-runtime-win-x64-04.zip` | 运行环境第 4 包 |

新建一个空文件夹，例如 `E:\RuoshuiComic`。依次右键这 5 个 ZIP，选择“全部解压缩”，**每次都将目标位置设为这个相同的文件夹**。它们是可单独解压的普通 ZIP，解压后会合并成完整的软件目录。

```text
RuoshuiComic/
├─ ruoshui-comic.exe
├─ resources/
└─ runtime/
```

全部解压完成后，双击 **`ruoshui-comic.exe`**。移动软件时保留整个文件夹。

`ruoshui-setup-guide.zip` 是可选的说明与校验工具包。需要校验时，将其解压到与程序相同的文件夹，进入 `安装说明` 子文件夹运行 `verify-packages.cmd`；原始 ZIP 放在安装目录中。

Release 页面中的 `Source code` 为源码下载，日常使用请选择安装器或上面的整合包。

## 开始创作

1. **检查环境**：打开设置中的环境检测，确认运行环境和显卡状态。
2. **准备模型**：在模型下载页面下载或导入所需模型。模型默认保存到当前软件目录，无需借用其他绘图软件的模型文件夹。
3. **生成或导入图片**：在“单图生成”输入提示词生成画面，也可上传已有图片进行局部重绘。
4. **制作漫画**：新建项目和画布，添加分镜、放入图片，再调整对白、文字、贴纸与图层顺序。
5. **导出作品**：点击“导出漫画 PNG”，图片按项目名称保存到独立子文件夹；旁边的“打开漫画文件夹”可直接查看结果。

单图生成和局部重绘各自保存结果。只有从具体分镜打开生成或重绘窗口时，结果才会回填到对应分镜；普通单图创作不会自动添加到漫画中。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 缩放漫画主画布 | Ctrl + 滚轮 |
| 缩放其他图像预览 | 直接滚轮；双击适合窗口 |
| 调整数值 | 先点击数值输入框，使边框高亮后再滚动滚轮；Shift 加快调整 |
| 滚轮步长 | 比例 / 倍率 0.1，整数参数 1，生图与重绘宽高 32，漫画尺寸 1，LoRA 强度 0.01 |
| 恢复参数 | 使用参数旁的恢复按钮，或在设置中恢复所有参数 |
| 调整图层顺序 | 右键图层，选择组内移动或跨类型图层移动 |
| 修正抠图位置 | 选中抠图，在属性中点击“自动对齐原图” |
| 导入字体 | 在文字字体选择处导入 TTF、OTF、WOFF 或 WOFF2 文件 |

## 数据保存与备份

项目文件、应用设置与独立运行环境保存在以下位置：

| 位置 | 内容 |
| --- | --- |
| `works/` | 项目、图片、设置、自动保存、词库与日志 |
| `works/exports/` | 按项目名称分类的漫画导出图片 |
| `works/fonts/` | 导入的字体 |
| `runtime/` | 独立运行环境与模型 |
| `runtime/ComfyUI/models/` | 按类型分类的模型文件 |

请定期备份 `works`，以及需要保留的模型。移动整合包后，后续模型下载和创作数据会跟随新的软件位置。
